• Project America Combine: standardized performance snapshots and notes.
• Experiment Lab: N=1 A/B protocol registry with no automatic adoption.
• Program Simulator: transparent trade-off rules for swimming, running/speed, arms, dunk emphasis, and time constraints.
• After Action Review: six-week completion view plus evidence-based change doctrine.

PRESERVED FROM V1.18
Existing training blocks, Giant A/B/C, Strength Methods, Giant B activators, final-set-only hypertrophy intensifiers, structured method logging, loaded stretches, COMPACT/MED, durable sessions, cardio machine tracking, mobility tiers, Exercise Arsenal, progress, backup/restore, and PWA/offline support.

IMPORTANT
Readiness is a simple self-report training check-in, not a medical/recovery diagnosis. Training Budget bars count recent exposures and are not claimed to be maximum recoverable volume. Project America never silently changes the master template.

DOCTRINE
The app does the bookkeeping. You do the training.
The system stays stable; performance inside it evolves.
Raise the weakest stat. Maintain the weapons.
Known ≠ estimated ≠ unknown.
If the program is working, don't touch it.
